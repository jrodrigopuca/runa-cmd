# ADR-0043: Un comando se escribe de una sola forma

- **Estado:** aceptada
- **Drivers:** `meta.name` es obligatorio, pero en `defineCLI` manda la clave: `with-output` da 127 si la clave es `withOutput` (F-03), y eso va contra [ADR-0029](./0029-cada-campo-tiene-efecto.md). Las flags convierten su nombre porque `run()` las lee como propiedad. A un comando nadie lo lee así, por lo que puede tener un solo nombre, sin costo en el código. [La investigación](../research/2026-10-naming-forms.md) muestra que aceptar otra forma es opcional en las herramientas que la permiten, y clig.dev pide minúsculas y guiones para los comandos.
- **Decisión:** la clave de un comando o grupo es su nombre, sin conversión, en la terminal, la ayuda, las completions, el config y la tool. Solo acepta minúsculas, números y guiones: `commands: { 'with-output': withOutput }`. Otra forma falla al arrancar con un error para el autor que indica la correcta. `meta.name` es opcional en un subcomando, y si se escribe, debe coincidir con la clave, o falla al arrancar. `runCLI` lo sigue exigiendo, porque es el nombre de la CLI. Una tool sigue siendo la ruta unida con `_`, como dice [ADR-0017](./0017-mapeo-de-comandos-a-tools-mcp.md). No se aceptan dos formas de un nombre, ni en comandos ni en flags. Las flags siguen según [ADR-0024](./0024-kebab-case.md).
- **Alternativas descartadas:** convertir la clave a kebab-case, como las flags, deja dos formas sin ganar nada, porque nadie lee un comando como propiedad. Dejar que mande `meta.name` escribe el nombre dos veces, y le quita el efecto a la clave. Aceptar varias formas deja dos sintaxis en el contrato para siempre; se puede agregar una tolerancia en una minor, pero quitarla exige una major.
- **Costo aceptado:** la clave de un comando de varias palabras va entre comillas. Una CLI con comandos en camelCase tiene que renombrarlos, y sus tools cambian de nombre. Un guión en el nombre de una tool no se comprobó con clientes MCP reales.
- **Revisar si:** un cliente MCP rechaza tools con guión, o un autor necesita otra forma por un contrato ya publicado.
