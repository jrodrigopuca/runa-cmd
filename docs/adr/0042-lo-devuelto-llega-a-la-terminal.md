# ADR-0042: Lo que devuelve un comando llega a la terminal

- **Estado:** aceptada
- **Drivers:** lo que devuelve `run()` llega por MCP, pero en la terminal sale vacío con exit 0 (F-01), aunque [`VERSIONING.md`](../../VERSIONING.md) promete que los resultados van a stdout. El rodeo es imprimir y además devolver, y sin `output` los tipos ni siquiera lo permiten (F-12). [ADR-0020](./0020-un-comando-para-personas-y-agentes.md) pide un comando para personas y agentes. AWS separa los datos de su presentación con un solo ajuste, como muestra [la investigación](../research/2026-10-aws-cli-lessons.md), pero su público son desarrolladores: el destino de Runa incluye a personas en una terminal, así que JSON no es un buen valor por defecto.
- **Decisión:** en la terminal, lo devuelto sale por stdout: con `format(result)` si el comando lo declara; si no, un string tal cual, y cualquier otro valor como JSON. Devolver `undefined` no imprime nada, salvo que el comando declare `format`: ahí es un error del autor, para que la terminal no quede vacía. `format` no corre por MCP, que recibe el dato. Un comando con `format` recibe `--json` de forma automática, que imprime el dato como JSON y no llega a la tool. `run()` puede devolver un valor sin `output`. Si el comando declara una opción `json` y también `format`, falla al arrancar, como las colisiones de [ADR-0014](./0014-colision-de-opciones.md).
- **Alternativas descartadas:** mostrar lo devuelto solo con `--json`, como oclif, conserva la terminal vacía. JSON siempre, como AWS, es mala primera impresión para una persona. Un `--json` global aparece en comandos que no devuelven nada. `--output` como flag del framework choca con CLIs reales: qr-plus lo usa para un archivo. `ctx.invocation` en `run()` deja de hacer falta para evitar formatear.
- **Costo aceptado:** es un cambio incompatible: un comando que imprime y devuelve muestra la salida dos veces, y debe mover la impresión a `format`. `json` queda reservada en comandos con `format`. Un objeto sin `format` se ve como JSON, aunque esté pensado para personas.
- **Revisar si:** los autores piden otro formato además de JSON, o un consumidor necesita filtrar campos, como `--jq` de gh o `--query` de AWS.
