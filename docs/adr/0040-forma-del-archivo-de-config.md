# ADR-0040: La raíz del config tiene las globales y los comandos

- **Estado:** aceptada
- **Drivers:** hoy una clave se aplica a toda opción con ese nombre: `{"force":true}` activa `--force` en cualquier comando, y una clave de `add` rompe `list` con exit 2 (H2 de [la evaluación](../research/2026-10-first-use-evaluation.md)). `{"clear":{...}}` se ignora sin aviso. El formato es contrato: cambiarlo después de la 1.0 exige una major. En [la investigación](../research/2026-10-config-file-shapes.md), Click, click-extra, Bun, Cargo, Ruff, Deno y uv ponen el comando o su familia en la raíz, y ninguna fuente usa una sección `commands`.
- **Decisión:** una clave de la raíz es una opción global, o el nombre de un comando o grupo. Un comando contiene sus opciones, y un grupo contiene sus comandos, anidados: `{"store":"./data","tag":{"add":{"priority":"high"}}}`. Con `runCLI` no hay nombre que escribir, así que las opciones del comando van en la raíz. Una clave desconocida da exit 2, y nombra el archivo y la clave; `$schema` se acepta. Si una CLI declara `config` y una global se llama igual que un comando o grupo, falla al arrancar, como las colisiones de [ADR-0014](./0014-colision-de-opciones.md). Un error de valor nombra el archivo y la clave, y un JSON roto se reporta como error del archivo, no como `Unexpected error`. La búsqueda sigue siendo `['.', '~']`, y el primer archivo gana: el riesgo de leer el directorio actual queda en manos del autor, que puede cambiar `searchPaths` o declarar `configurable: false` en una opción, para que solo la terminal pueda fijarla. `--mcp` lo declara: si no, un archivo en el directorio convertiría `tool list` en un servidor. Los nombres son los mismos que define [T-213](../backlog.md#t-213-nombre-de-los-comandos), y las opciones usan su clave, como dice el README de `core`.
- **Alternativas descartadas:** mantener el formato plano y sumar un lugar por comando conserva el problema, porque `force` en la raíz seguiría activando todos los `--force`. Una sección `commands` evita el choque, pero suma un nivel y no apareció en la muestra. Comandos en la raíz sin control repiten lo que click-extra advierte: una clave significa dos cosas, y puede perderse un valor. Una ruta como `"tag add"` no aparece en la muestra. Una advertencia ante una clave desconocida deja el resultado incorrecto, aunque Cargo y Prettier lo hacen; Bun (`lint`, `fmt`) y Ruff dan error. Una sección compartida `defaults` se puede agregar después, sin romper nada.
- **Costo aceptado:** rompe los archivos planos actuales. Un valor común a varios comandos se repite, o pasa a ser global. Una global y un comando con el mismo nombre no pueden convivir en una CLI con config. Un archivo escrito para una versión más nueva de una CLI falla en una más vieja. Un plugin no puede guardar claves propias en el archivo. `$schema` queda reservada, y una sección nueva de Runa en la raíz podría chocar con el nombre de un comando.
- **Revisar si:** un plugin real necesita claves propias, o hay quien pida compartir valores entre comandos con evidencia de uso.
